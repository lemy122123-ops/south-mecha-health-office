## GitHub Pages

Upload all files to a GitHub repository, then go to:

Settings -> Pages -> Build and deployment -> Deploy from a branch -> main -> / (root) -> Save

Replace placeholder contact information, logo, official social links, approved vision/mission and approved performance data before public launch.

Do not upload patient-identifiable, confidential or credential information.
